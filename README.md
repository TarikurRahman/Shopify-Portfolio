# Shopify Portfolio

A modern, responsive portfolio website for Tarikur Rahman, a Shopify expert developer and eCommerce consultant. The site presents Shopify development services, technical expertise, featured projects, client testimonials, and contact options in a polished single-page experience.

## Project Overview

This project is built with Next.js and React to showcase professional Shopify and eCommerce development work. Visitors can explore:

- Shopify development expertise and supporting technologies
- Service packages for businesses at different growth stages
- Featured project case studies and measurable outcomes
- Client testimonials in an interactive carousel
- About information and professional achievements
- A contact page with a project inquiry form

## Tech Stack

- **Framework:** Next.js 16
- **Language:** TypeScript
- **UI:** React 19, Tailwind CSS, Radix UI, and custom components
- **Icons:** Lucide React
- **Animation and interaction:** GSAP, Lenis smooth scrolling, and Embla Carousel
- **Analytics:** Vercel Analytics
- **Package manager:** pnpm

## How to Install & Run

### Prerequisites

Make sure the following tools are installed:

- [Node.js](https://nodejs.org/) 20 or later
- [pnpm](https://pnpm.io/installation)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/TarikurRahman/Shopify-Portfolio.git
   ```

2. Move into the project directory:

   ```bash
   cd Shopify-Portfolio
   ```

3. Install the dependencies:

   ```bash
   pnpm install
   ```

4. Start the development server:

   ```bash
   pnpm dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Available Scripts

| Command | Description |
| --- | --- |
| `pnpm dev` | Starts the development server. |
| `pnpm build` | Creates an optimized production build. |
| `pnpm start` | Starts the production server after building. |
| `pnpm lint` | Runs ESLint checks across the project. |

## Main Routes

- `/` - Portfolio homepage with hero, skills, services, projects, testimonials, and footer
- `/about` - Developer profile, journey, achievements, and professional network
- `/contact` - Contact details and project inquiry form
- `/robots.txt` - Search engine crawler instructions
- `/sitemap.xml` - Search engine sitemap

## Features

- Responsive layout for mobile, tablet, and desktop screens
- Shopify-focused developer portfolio presentation
- Hero section with project and business performance statistics
